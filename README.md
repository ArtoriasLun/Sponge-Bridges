Official homepage for **Sponge Bridges**.

## 玩家反馈 / Player feedback

在游戏里碰到问题，或者想提建议，都可以直接在这个仓库里说 ——
Found a problem in the game, or want to suggest something? File it right here:

| | |
|---|---|
| [🐛 报告问题 / Report a bug](https://github.com/ArtoriasLun/Sponge-Bridges/issues/new?template=bug_report.yml) | 出错了、卡住了、崩溃了 |
| [💡 提个建议 / Suggest something](https://github.com/ArtoriasLun/Sponge-Bridges/issues/new?template=suggestion.yml) | 想要的功能、想改的手感、想加的内容 |
| [🌐 文本与翻译 / Text and translation](https://github.com/ArtoriasLun/Sponge-Bridges/issues/new?template=translation.yml) | 错别字、读着别扭、显示不下 |
| [📋 已提交的全部问题 / Everything filed](https://github.com/ArtoriasLun/Sponge-Bridges/issues) | 动笔之前先搜一下，有人提过就去补充 |

提交之前请注意：这里是公开的，所有人都能看到你写的内容。**不要贴出邮箱、真实姓名或存档里的个人信息。**
不方便公开的事情，走 [支持表单](https://artoriaslun.github.io/Sponge-Bridges/support.html)。

Note before you post: this tracker is public. **Keep your email, real name, and anything personal
out of it.** If it's private, use the [support form](https://artoriaslun.github.io/Sponge-Bridges/support.html) instead.
