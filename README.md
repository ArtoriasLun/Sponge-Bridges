# Sponge Bridges

Official homepage for **Sponge Bridges**.

`index.html` is the entire site — a single self-contained static page, no
build step, no dependencies beyond Google Fonts. This repo holds only the
public-facing homepage; nothing else is ever meant to go in here.

Live at: https://artoriaslun.github.io/sponge-bridges/ (once Pages is
enabled — Settings → Pages → Source: Deploy from a branch → `main` / `(root)`).
